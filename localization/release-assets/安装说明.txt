Exile UI PoE1 简体中文语言包安装说明
====================================

本压缩包只包含 data 目录中的语言文件，不会修改 Exile UI 源码。

1. 完全退出 Exile UI，包括系统托盘中的后台进程。
2. 将压缩包内的 data 文件夹解压到 Exile UI 根目录并合并。
   正确位置应为 data\zh-CN。
3. 启动 Exile UI。
4. 打开设置的“常规/UI”区域，在语言下拉框中选择 zh-CN。

说明：

- 语言包只包含 PoE1 的 UI、剧情指南、区域名称、帮助文本和 PoB 宝石名称。
- `client.txt`、中文客户端日志、物品文本和 OCR 适配不在本包中。
- PoE2 程序和英文数据保留在 Exile UI 根目录中；本包不提供 PoE2 中文资源。

卸载语言包时，完全退出 Exile UI，然后删除 data\zh-CN。
