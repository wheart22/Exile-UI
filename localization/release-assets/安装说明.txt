Exile UI PoE1 简体中文整合版安装说明
======================================

本压缩包已经包含完整的 Exile UI 程序、运行数据和 PoE1 简体中文资源，
不需要安装或覆盖原版 Exile UI。

1. 将整个压缩包解压到任意目录，不要只解压其中的 data 文件夹。
2. 如果电脑没有 AutoHotkey v1.1，请先从 https://www.autohotkey.com/ 安装。
3. 双击解压目录中的 `Exile UI.ahk` 启动程序。
4. 首次启动后，打开设置的“常规/UI”区域，在语言下拉框中选择 `zh-CN`。

说明：

- PoB 导入后的主动宝石、辅助宝石和宝石链接显示为“简体中文名（English name）”。
- 英文游戏客户端搜索逻辑保持不变。
- 当前版本不包含中文 `client.txt`、物品文本和 OCR 适配。
- PoE2 程序和英文数据保留在整合包中，但本包只提供 PoE1 简体中文资源。

卸载时，完全退出 Exile UI 后删除解压出来的整合包目录即可。
